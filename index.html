Lab instructions

  1. Add a battery, resistor and LED (or load the example).
  2. Click a pin on one component, then click a pin on another component to draw a wire.
  3. For the LED to glow, connect battery + → resistor → LED anode (+), then LED cathode (−) → battery −.
  4. Press Run simulation. Move parts by dragging their body.

Arduino & component connection guide

Arduino Uno/Nano: module VCC → board 5V (only if module supports 5V), GND → GND, signal → suitable digital/analogue pin.

ESP32: use 3.3V logic. Never apply 5V to GPIO. Connect module GND to ESP32 GND.

LED: GPIO → 220–330 Ω resistor → LED anode (+); LED cathode (−) → GND.

Potentiometer/LDR: create a voltage divider between supply and GND; connect the centre/junction to an analogue input.

Servo: signal → PWM-capable pin; use a suitable external supply if needed; join external GND to board GND.

HC-SR04 ultrasonic: VCC, GND, TRIG and ECHO to matching pins. Level-shift ECHO for 3.3V boards.

I²C (OLED/sensors): connect VCC, GND, SDA and SCL to the board's documented I²C pins.

SPI modules: connect VCC, GND, SCK, MOSI, MISO and CS to matching SPI pins.

Motors/relays: use a rated driver and supply; never power motors directly from GPIO. Use flyback protection for inductive loads.

Safety: exact pinouts vary by board/module. Check the datasheet. Do not connect mains voltage to this virtual breadboard.

Virtual Electronics Lab is a learning-focused website concept for discovering electronic components and tools. The library includes common examples across hobby electronics, embedded development, power electronics, communications, audio/video, automation, and lab testing. It can be expanded with datasheets, circuit simulations, pinout diagrams, and project tutorials.
